🔑 הגדרה חד-פעמית: מפתח Gemini חינמי

המחוללים מבוססי ה-AI עובדים עם מפתח אישי חינמי של Google — כך כל משתמש/ת עצמאי/ת לגמרי, בלי תלות באף אחד ובלי עלות. המפתח נשמר רק במכשיר שלכם ולא נשלח לשום שרת.

  1. נכנסים עם חשבון Gmail אישי (מייל ארגוני של בית הספר חוסם יצירת מפתחות) אל aistudio.google.com/apikey
  2. לוחצים על Create API key ומעתיקים את המפתח
  3. מדביקים אותו במחולל כשמתבקשים — פעם אחת בלבד לכל מכשיר
